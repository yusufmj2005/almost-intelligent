# Almost Intelligent Systems

> “We Make Intelligence Work. Eventually.”

Official website for **Almost Intelligent Systems** — a two-person software development team building practical software, full-stack web applications, Python tools, AI/ML integrations, chatbots, data analytics dashboards, and workflow automations.

## About the Brand

Almost Intelligent is a self-aware, engineering-first development duo. The brand blends technical capability and practical experimentation with developer humour. We believe good technology should solve real problems without unnecessary corporate jargon.

## Capabilities

- **Websites & Full-Stack Apps:** Fast, responsive web applications, landing pages, and intuitive user interfaces.
- **Python & Automation:** Custom backend services, robust API integrations, scheduled automation pipelines, and data dashboards.
- **AI & LLM Integrations:** Practical AI chatbots, LLM-powered tools, ML prototypes, and workflow assistants.
- **Software Development:** Desktop utilities and mobile applications built for purpose.

## Tech Stack & Architecture

- Plain modern HTML5, CSS3, and vanilla JavaScript (ES6+)
- Scalable vector graphics (SVG) visual identity and favicon
- Live project enquiry form integrated with a serverless Google Apps Script backend
- Lightweight client-side assistant chatbot with deterministic pattern matching
- Accessible markup, smooth scrolling, responsive typography, and reduced-motion support
- Zero external build dependencies or heavy frameworks

## Running Locally

To preview the website locally:

```bash
# Using Python's built-in HTTP server:
python -m http.server 8000
```

Then visit `http://localhost:8000`.
